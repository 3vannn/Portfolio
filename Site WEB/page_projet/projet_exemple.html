🎯Contexte et besoin

Dans le cadre du BUT Informatique, chaque étudiant doit constituer un portfolio numérique permettant de mettre en valeur ses compétences et ses réalisations auprès de recruteurs, d'enseignants et de professionnels du secteur.

L'objectif était de créer un site web statique, complet et professionnel, sans recourir à un CMS ou à un framework complexe, afin de démontrer la maîtrise des technologies web de base (HTML, CSS, JavaScript).

🔧Ce qui a été réalisé

J'ai conçu et développé l'ensemble du site de A à Z : structure, design, intégration et comportements interactifs. Voici les principales réalisations :

  • Page d'accueil avec mise en page hero bi-colonne (photo + présentation)
  • Page "À propos" avec timeline de parcours et centres d'intérêt
  • Page compétences avec accordéon interactif (6 compétences BUT Informatique)
  • Page de projet avec carrousel d'images et bouton de téléchargement
  • Page de contact avec formulaire fonctionnel (Formspree)
  • Navigation responsive avec menu hamburger sur mobile
  • Charte graphique cohérente via CSS custom properties (variables)
